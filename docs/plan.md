## 1. 先把论文口径对齐（这一节防止全组跑偏）

### 1.1 Section 5 到底做了什么

| 小节 | 模型 | 对冲工具 | 成本 | 风险测度 | 关键产出 |
|---|---|---|---|---|---|
| 5.1 | 通用设定 | d 个 | 比例成本 c=ε\|Δn\|S | — | 半递归网络、30 步日频、N1=N2=d+15 |
| 5.2 | Heston | d=2：标的 + 方差互换 | 0 | avg-VaR/CVaR | Fig2–9：学回 model delta、风险偏好改变策略 |
| 5.2 脚注 | 同上 | 同上 | **ε=0.01** | CVaR 0.99 | Fig5：**有成本时架构才重要** |
| 5.3 | BS d=1 / Heston d=2 | d=1 标的 / d=2 标的+方差互换 | ε∈{2^-6,…,2^-10}（156→9.8bp） | entropic λ=1 | Fig10/11：p_ε−p_0 = O(ε^{2/3}) |
| 5.4 | 5 个独立 Heston，d=10 | d=10 | 0 | 方差最优 | 可扩展性（**我们不做**） |

论文的超参（5.1）：T=30 个交易日、日频调仓、n=30 步、t_i=i/365；半递归 δ_k=F_k(I_k,δ_{k−1})，F_k 为 2 隐层前馈，N0=2d、N1=N2=d+15、N3=d，ReLU + 每层 batch norm，**每个 k 的网络权重不同**；Adam lr=5e-3、batch=256。

Heston 参数（5.2）：均值回复 α=1、长期方差 b=0.04、ρ=−0.7、vol-of-vol σ=2、v0=0.04、s0=100；call K=s0、T=30/365。风险中性价 q=1.69；无差异价 pθ0：α=0.5 → **1.94**，α=0.99 → **3.49**。

### 1.2 三个最容易搞错的地方

1. **主线不是"BS + 成本"**。5.2 是 Heston **d=2**（标的 + 方差互换）**零成本**；成本只出现在 5.2 的一个脚注图（ε=0.01）和 5.3 的定价渐近。照 v0 的路子做"BS+成本"会直接跑偏。
2. **5.3 的 ε 是"小成本"而不是"大成本"**：ε_i = 2^{−(i+5)}，i=1..5 → {1/64, 1/128, 1/256, 1/512, 1/1024} = **156.3 / 78.1 / 39.1 / 19.5 / 9.8 bp** 的单边成本。它验证的是 ε↓0 时 **p_ε − p_0 = O(ε^{2/3})**（式 5.8）的收敛速度，**不是**极端成本下的稳健性，也**不是**能外推到 10bp 的"大 ε 区间"——恰好相反，9.8bp 就是它自己的下界。核对方法：tex 源码写的是 `2^{-{i+5}}`，Fig 10 横轴就是这 5 个 `ln(2^{-6..-10})` = −6.93…−4.16（横轴标 `log(ε)`，是自然对数；换底只改截距、不改 2/3 斜率）。报告里要专门写这一句。
3. **5.2 的 benchmark 要求 d=2 齐全**。model delta 是 (δ1 对标的, δ2 对方差互换)。港股没有方差互换 → 港股段必然是 d=1，属于**扩展**，必须单列，不能和论文结论混着说。

## 2. 复现靶子（A 组）

统一约定：5 个 seed（0–4），报均值，出图用 seed 0；每条结果落 `results/<exp>/<seed>/metrics.json`；图存 `results/<exp>/fig_*.png`。

**成本口径（冻结，按论文 (5.7)）**：`c_k = Σ_i ε_i |δ_i,k − δ_i,k−1| · S_i,k`，`δ` 是**单位数**、`S_i,k` 是工具 i 在 t_k 的**价格**，成本按**名义本金**收；首次建仓取 `δ_i,−1 = 0`（t=0 建仓计费），到期不强制平仓。

- d=2 两腿量级差 4–5 个数量级：标的 `S¹ ≈ 100`、方差互换价格 `S²_0 = bT ≈ 0.0033`（论文式 5.4：`S²_t = E_t[∫_0^T V_s ds] = 剩余段积分 + L(t,V)`，是**对冲工具本身的价格**，见 §2.5 与 §10.4）。同一个 ε 下，标的腿的单位成本是互换腿的 **≈3×10^4 倍**；再乘上两腿 `|Δδ|` 的量级，**E3「有成本时架构才重要」的效应仍由标的腿主导**（实际占比在 E3 seed 0 上实测后写进结论）。
- 写 E3 结论时按这个口径解释，不要写成「方差互换腿的成本让策略改变」；ε 可读作「标的腿的单边成本率」。
- E4 是单因子（5.3），只有标的腿，不存在这个量级差。

### E1 零成本、α=0.5：网络能不能学回 model delta
- **出处**：5.2，Fig 2 / 3 / 4
- **设定**：Heston(α=1, b=0.04, ρ=−0.7, σ=2, v0=0.04, s0=100)，d=2（标的 + 方差互换），call K=100，T=30/365，30 步日频；测度 avg-CVaR(0.5)。
- **产出**：(a) Fig2 式损失直方图（网络 vs model hedge）+ 表；(b) Fig3 式在 t=15d 的 (S,v) 网格上对比 delta 面（我们的 vs model delta）；(c) Fig4 式 recurrent vs simpler 对照。
- **判据**：
  - pθ0 ∈ **[1.80, 2.10]**（论文 1.94），q≈1.69（定价器自检用）
  - delta 面与 model delta 的 RMSE **< 0.15**（S∈[90,110] 网格上；v1.4 放宽：纯监督拟合解析 δ 的极限也只有 ~0.065，见 `docs/e1_diagnosis.md` §6，这条阈值只用于抓 BN/训练跑飞）
  - recurrent 与 simpler 的价差 **< 3%**（论文结论：无成本时架构不重要）
- **风险**：benchmark 要自建，见 §2.5。

### E2 零成本、α=0.99 与 call spread：风险偏好会不会改变策略
- **出处**：5.2，Fig 6 / 7 / 8 / 9
- **设定**：E1 同模型；α=0.99；再做一个 call spread（K1=100, K2=101），α∈{0.95, 0.99}。
- **产出**：两档 CVaR 的损失直方图（Fig6）+ 归一到 q 的价（Fig7）+ call spread 的策略形态（Fig8/9 定性即可）。
- **判据**（核心是**分布交叉**，不是单个数字）：
  - pθ0(0.99) ∈ **[3.2, 3.8]**（论文 3.49）
  - 0.99 策略的 realized 0.5-CVaR **高于** 0.5 策略（论文 0.527 vs 0.253）
  - 而 0.99 策略的 realized 0.99-CVaR **低于** 0.5 策略（论文 1.803 vs 2.363）
  - 两条分布不交叉 = 没复现出风险偏好的实质，要排查
  - call spread 在 α=0.99 时仓位区间明显收窄（论文解释为 barrier shift）

### E3 有成本 ε=0.01、α=0.99：架构什么时候变重要
- **出处**：5.2 脚注 + Fig5
- **设定**：同 E1；比例成本 c_k = ε·|Δn|·S，**ε=0.01（100bp/边）**；α=0.99；recurrent 与 simpler 两套网络，同训练预算、同 seed。
- **产出**：一张三行表（mean loss / 无差异价 / realized CVaR）。
- **判据**：recurrent 价 ≈5.51（区间 [5.2,5.8]），simpler ≈6.74（[6.4,7.1]）；realized CVaR recurrent ≈ −0.002，simpler ≈ 0（论文是截断值 −0.0，实现时保留原始数）；**recurrent 严格更优**。
- **备注**：论文这一格的"价格"是无差异价，不是 BS 价；数值量级大（5–7）是因为效用函数与成本都极端。

### E4 定价渐近：p_ε − p_0 是不是 ε^{2/3}
- **出处**：5.3，式 (5.8)，Fig 10 / 11
- **设定**：entropic 测度（式 3.4，λ=1）；BS d=1（σ=0.2, s0=100, I_k=log S_k），Heston d=2 同 5.2 设定；**ε_i = 2^{−(i+5)}，i=1..5** → {156.3, 78.1, 39.1, 19.5, 9.8} bp；每个 ε 训一个策略得 p_ε，对 (ln ε, ln(p_ε−p0)) 做最小二乘（论文 Fig 10 横轴即 `log ε`，自然对数）。
- **判据**：BS 斜率 **0.67 ± 0.04**；Heston 斜率 **0.71 ± 0.05**；R² > 0.95。
- **顺序**：BS 那条先做通（有解析对照、p0 可直接取 q，最省事），再上 Heston。
- **风险**：ε 越**小**，`p_ε−p0 ∝ ε^{2/3}` 越**小**（9.8bp 时差值只有 1e-2 量级），log 差的纵向噪声被放大 → 每条 ε 需要 ≥1e5 条路径、并用 5 个 seed 取均值；若 Heston 的 p_ε 曲线噪声大，先把路径数拉到 2e5。

**低摩擦附表（扩展，必做）**：论文网格的低端 9.8bp 已经低于港股 ETF 腿（~30bp），但高于期货腿（~1bp）。所以附表只**往下**补：ε ∈ {2^-11, 2^-12, 2^-13}（≈4.9 / 2.4 / 1.2 bp），**先跑 seed 0–2，区分不开再补 3–4**，单独拟合斜率，回答"2/3 律在 1bp 附近还成不成立"。判据：低 ε 段先看 **seed 间标准差 < (p_ε−p0)/5**，满足才报斜率，不满足就写"1bp 档无法分辨"（这本身也是结论）。这组结果用来解释港股预期 1（1bp 上为什么应打平），报告里和 §4.1 串起来写。

### E5（明确不做）高维 d=10
论文 5.4 用 5 个独立 Heston 拼出 d=10、方差最优目标，训练 2×10^5 步，X1 Carbon 上 5.75h vs 2.1h、realized loss 1.13 vs 0.20（解耦）。我们**不复现**，理由写进报告：算力 + 与本科项目要回答的问题无关；只在 related work 里提一句。

### 2.5 benchmark model hedge 的实现路径（A1 的关键任务）
pfhedge 有 `HestonStock`（kappa/theta/sigma/rho）和 `VarianceSwap`，但 **nn 里只有 BS 解析价**，Heston 期权价要自建。三条路，按顺序试：

1. **特征函数法（首选）**：Heston call 的 Lewis/Carr–Madan 公式，1 维数值积分，向量化后可算 1e5 条路径；方差互换价格用闭式 `S²_t = ∫_t^T E_t[V_s] ds`（`E_t[V_s] = b + (v0−b)e^{−α(s−t)}`，单位是方差×时间，S²_0 = bT ≈ 0.0033；**不是**除以 T 的年化 fair strike），每日 mark = 已实现段 + 剩余期限闭式。δ1=∂C/∂S，δ2=∂C/∂(varswap 价) 由链式法则（经 v_t）得到。
2. **bump-and-revalue（次选）**：MC 重估两次（S±h），只用于 t=15d 的 delta 面验证，不用于全量回测。
3. **降级路径**：只对冲标的，benchmark 用 Heston delta（固定 v）或 BS delta。

**检查点 B0（开 E1 训练前必须过）**：三个对拍同时成立才走路径 1——解析 Heston call vs pfhedge 1e5 条路径 MC 差 **< 1.5%**；方差互换闭式 vs MC 差 **< 1%**；中间时点 mark（剩余期限闭式 + 已实现方差）vs "从该时点重新 MC" 差 **< 1%**。有一个不过，先疑似散化（dt、方差过程截断方式），仍不过则走路径 3。

> 降级的正确做法是**只砍 E1 的对比部分**（直方图、delta 面），E1 仍交 pθ0∈[1.80,2.10] 与架构对照；E2/E3/E4 不依赖 d=2 benchmark（E3 比的是 recurrent vs simpler 的无差异价，E4 的 p0 只要单因子价），全部照做。**不要整体转 d=1**——d=1 是 B 组的实验，A 组转过去会两组撞车。

## 4. 港股验证设计（B 组）

### 4.1 一句话设计与两个可被打脸的预期
港股恒指期货往返成本约 **1bp**，远低于论文的 100bp 档；2800.HK 腿往返约 **30bp（25–40bp）**。主指标是 C\*（策略在真实路径上所需的期初资本，越低越好），于是有两个预期：

- **预期 1（成本阈值）**：在 ~1bp 的期货腿上，deep hedging 的 C\* 应**几乎等于** delta（与论文"无成本时架构不重要"同向）。
- **预期 2（成本上升后才出现优势）**：在 ~30bp 的 ETF 腿上，deep hedging 的 C\* 应**低于** delta（少交易、尾部更好，所需资本更少）。

这两个都能被数据打脸，**打脸也是结果**——报告里"优势不存在"同样成立。

### 4.2 标的与样本
- 主：`^HSI`，2010-01 ~ 2024-12，**180 个月度窗口**
- 稳健：`^HSCE`
- 训练/测试：2010–2018 训练（108 窗口），2019–2024 测试（72 窗口）；另用全样本重叠窗口 + block bootstrap 补 power
- 明确不做：恒生科技（2020-07 起，样本太短，CVaR95 只有 3 个尾部点）；日韩/美股（只在讨论里提）

### 4.3 数据与合成（B1）
| 序列 | 来源 | 用途 | 处理 |
|---|---|---|---|
| ^HSI / ^HSCE | Yahoo / Stooq 日收盘 | 标的路径 | 对数收益；缺失用前值 + 标记 |
| 2800.HK | Yahoo 复权价 | ETF 腿（真实可交易） | 复权、停牌标记 |
| 2800.HK 分红 | Yahoo 分红序列 | 股息率 q | 滚动 12 个月加总 / 价格 |
| HIBOR 1M | HKMA 开放 API | 无风险 r | 日频插值 |
| VHSI（可选） | 若能扒到 | IV 代理（仅对照表） | 优先于 GARCH 预测 |

- **期货腿**：合成恒指期货 F_t = S_t·exp((r_t − q_t)·τ)，τ 为剩余到期；回测用 ΔF/F 作为对冲工具收益。**期货不可交易的现实是：历史连续合约拿不到，只能合成**，这句要写进 limitations。
- **期权**：每月首个交易日卖出/买入 1 张 ATM call，K 取最接近的 100 点整数（按实际行权价列表取最近），T=30 天。
- **premium**：主口径（C\*）不需要 premium；仅 §4.7 的对照表用到 §4.4 的口径。

### 4.4 premium 假设（仅对照表用，B1 定，B2 用）
> 主指标是 §4.7 的 C\*，本节口径**不进主表**。
- **第一优先**：侦察 `^VHSI`（恒指 30 天 ATM IV 指数，Yahoo 上形如 `^VHSI`）。拿得到日频序列 → 对照表直接用真实 ATM IV，GARCH+VRP 降为敏感性；拿不到 → 走下面的模型口径，并在 limitations 写明
- 基准：GARCH(1,1) 条件方差 → BS 价，σ 取 GARCH 预测
- VRP 三档：σ × (1 + 0%) / 3% / 5%
- 说明：真实 HSI 期权 IV 通常高于 GARCH 预测（VRP 为正），5% 档接近经验值
- 若三档下策略排序翻转 → 说明对照表结论对 premium 假设敏感；主表（C\*）不受影响

### 4.5 成本参数（B1 出表，B2 实现）

- 2800.HK 每手 500 股、名义约 HK$1.2 万；对冲 1 张恒指 call（名义 ~HK$100 万）需 **~90–100 手** → 整手取整误差单列一项

### 4.6 三条策略腿
| 腿 | 说明 | 来源 |
|---|---|---|
| Bench | Heston/BS delta（d=1），每日按 delta 调仓 | B2 自写，用 B1 的 r,q,σ |
| M1 zero-shot | A 组 `policy_heston_d1` 直接搬到港股，**不重训** | A 组交付 |
| M2 re-fit | **参数化 GARCH 情景**（已定为主口径）→ 重训 d=1 → 测试段回测；历史 bootstrap 情景只作 robustness 附表 | B2 |

> **硬接口**：A 组必须额外训练并交付一个 **d=1**（只交易标的）的 policy，否则 B 组无 policy 可迁移。这是 A/B 之间唯一强依赖。

### 4.7 主指标：capital requirement C\*
零期初资本下的终端损失 `L = −X_T|_{C=0} = Z − (δ·S)_T + 成本`。因为风险测度是**现金可加**的，C\* 不用求根，直接算：

| 风险档 | 定义 |
|---|---|
| 95% | `C*95 = CVaR95(L)` |
| 99% | `C*99 = CVaR99(L)` |

C\* 的含义：在 180 个历史月度情景上，要让 95%（或 99%）情景的损失不亏，期初需要多少资本。**它不含任何 premium 假设**，只需要真实路径 + 真实成本 + 一个风险测度；这与论文的 pθ0 同构（论文的价格本身就是解出来的资本金）。

主表：成本档 × 策略 × {C\*95, C\*99, mean loss, turnover, cost/notional}

- **P1（期货 1bp）**：M1/M2 与 delta 的 C\*95 相对差 **< 5%**（预期"打平"）
- **P2（ETF ~30bp）**：M1/M2 的 C\*95 **低于** delta，paired block bootstrap 95% CI **不跨 0**（预期"优势出现"）
- **P3（风险偏好）**：α=0.99 训练的策略 C\*99 更低、但 C\*95 更高（与论文的分布交叉同向）
- **P4（迁移是否要本地重训）**：M2 vs M1 的 C\*95 差
- **统计**：monthly block bootstrap，block=12 个月，B=2000；180 个样本**不做 p<0.05 强断言**，只报点估计 + 95% CI
- **口径**：主表是 C\*，不含 premium 假设；对照表（若有 `^VHSI`）里 premium 是市场 IV 或模型价，那里的绝对 P&L 只作相对比较

## 10. 已拍板的决策（v1.2 / v1.3 / v1.4）

### 10.1 benchmark 卡住时的退法
**决定：不整体转 d=1。** 检查点 B0（三个对拍）过不了时，只砍 E1 的直方图与 delta 面对比；E1 仍交 `pθ0 ∈ [1.80, 2.10]` 与 recurrent vs simpler 对照；E2/E3/E4 全部照做。
**理由**：d=1 是 B 组要回答的问题（不完全市场里网络能不能打败 delta），A 组转过去两组就撞车了；而 E2/E3/E4 本身不依赖 d=2 benchmark。

### 10.2 港股主指标：capital requirement C\*
**决定：主口径换成 C\*，不再假设 premium。**
- 理由：论文本身走的就是"风险测度 + 无差异定价"路线，pθ0 是解出来的资本金，不是市场报价；过去"收 premium 算 P&L"反而偏离论文
- C\* 是零期初资本下的 CVaR95/99 损失（现金可加，闭式，不用求根），不需要 premium、IV、VRP
- `^VHSI` 降为加分项：可得就出一版真实 ATM IV 的 premium − P&L 对照表，证明主结论不依赖 premium 口径
- 话术不变：论文的成本结论在 ε=100bp（E3）下展示，E4 的渐近网格本身也已覆盖到 9.8bp；港股真实成本是 **1bp（期货）/ ~30bp（ETF）**——期货腿比 100bp 低两个数量级，ETF 腿与 100bp 只差约 3 倍。我们检验这个结论在低摩擦区还成不成立。研究对象是**成本阈值**，C\* 让它完全不依赖 premium 假设

### 10.3 E4 的 ε 网格
**决定：主表照抄 ε_i = 2^{−(i+5)}，i=1..5**（{156.3, 78.1, 39.1, 19.5, 9.8} bp；这是和 0.67/0.71 可比的唯一方式），**另补低摩擦附表 {2^-11, 2^-12, 2^-13}**（≈4.9/2.4/1.2bp，只向下延伸）。低 ε 段先看 seed 间标准差是否小于 `(p_ε−p0)/5`，不满足就写"无法分辨"。
**理由**：5 个点做最小二乘太单薄，8 个点能给出斜率的标准误；低 ε 段的结果正好解释港股预期 1。

### 10.4 d=2 的输入特征与网络宽度（v1.3，v1.4 修正 varswap 口径）
**决定：冻结 f=3，`x_k = [log(S_k/S_0), t_k/T, varswap_k/varswap_0]`。** `varswap_k` 取**论文式 (5.4) 的方差互换价格** `S²_k = E_{t_k}[∫_0^T V_s ds]`（剩余段积分 + `L(t_k,V)`；是可交易的 MTM 价格、martingale；`S²_0 = bT ≈ 0.0033`），**不是**年化 fair strike、也不是瞬时方差 `v_k`；`varswap_0` 同口径。网络宽度：输入层 `f + d`（d=1 为 3、d=2 为 5），隐层 `N1 = N2 = d+15`，输出 `d`。
**理由**：每步一个独立网络，`t_k/T` 在该步是常数、被 bias 吸收，加它不增加信息也不改拟合；用工具**价格**（而不是 `v_k`）进 δ2 的链式法则，与论文「输入是对冲工具价格」的精神一致，也和成本口径同源。**注意不能用年化 fair strike（`S²/T`，量级 0.04）**：它带漂移、不是 martingale，CVaR 优化会去套这个假漂移（价格 1.69→1.34），实测记录见 `docs/method_replication.md` §2。
**与论文的差异**：论文用 `I_k = (log S¹_k, V_k)`（f=2，N0=2d）。我们 f=3、N0=f+d，**记为 documented deviation**，写进 `docs/method_replication.md`，不追求与论文逐位一致。

### 10.5 成本口径：按名义本金（v1.3）
**决定：按 (5.7)，`c_k = Σ_i ε_i|δ_i,k − δ_i,k−1|S_i,k`，`δ` 是单位数、`S` 是工具价格；首次建仓 `δ_{−1}=0` 计入，到期不强制平仓。**
- d=2 下标的 ≈100、方差互换价格 ≈0.0033（`S²_0 = bT`），同 ε 时**标的腿的单位成本约为互换腿的 3×10^4 倍**。
- 推论：E3 的「有成本时架构才重要」在本口径下**几乎全部由标的腿驱动**；结论段必须这样解释，ε 可读作「标的腿的单边成本率」。
- B 组映射港股成本档（1bp 期货 / ~30bp ETF）时按同一口径（标的腿）折算。

### 10.6 E4-BS 的环境归属（v1.3）
**决定：A1 交付 `src/replication/env_bs.py`**——BS d=1 世界 + entropic loss，与 `env_heston.py` 同一套 `step / payoff / cost` 接口（路径 `(B, 31)`，30 步日频）。
**理由**：spec 原目录只有 `env_heston.py`；A2 的 E4-BS 若无现成环境会自写第二套模拟器，而 B0 三对拍只覆盖 Heston 那套，等于留一个没被验证的组件。A1 顺手给，A2 直接复用；并在单测里加一条 BS 解析价 vs MC 的黑箱对拍（1e5 路径，差 < 1%），不额外占用 B0 的三个 Heston 对拍。
